# Thirnex - Password Strength Analyzer

A modern secure authentication system with live password strength analysis.

## Features

- Password Strength Analyzer
- Signup/Login System
- Username Validation
- Password Suggestions
- Forgot Password
- Security Questions
- Old Password Prevention
- SQLite Database
- Modern UI Design

## Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- SQLite

## How to Run

### Backend

```bash
cd backend
npm install
npm run dev
```

### Frontend

Open `index.html` using Live Server.

## Project Workflow

User Signup → Password Analysis → Login → Dashboard → Forgot Password → Reset Password
